# Mobile example

An Expo app (iOS and Android) styled with Pickle's tokens through
[Uniwind](https://uniwind.dev): the same project list and form as the web
example, a light / dark / system switch and runtime brand colors.

```bash
pnpm example:mobile   # from the repository root, then press i or a
```

There is no `@pickle-ui/react-native` package yet, so `src/components` holds
small local components (`Button`, `Badge`, `Card`, `Text`) built on React
Native primitives. They reuse the web API's names (`variant`, `size`, `tone`,
`Card.Header`, …) and only the token utilities (`bg-primary`,
`text-muted-foreground`, `border-border`, `rounded-xl`).

## Files

| File                               | Shows                                                              |
| ---------------------------------- | ------------------------------------------------------------------ |
| `metro.config.js`                  | `withUniwindConfig` pointing at the CSS entry                      |
| `src/global.css`                   | Setup and token overrides as Uniwind themes                        |
| `src/app/_layout.tsx`              | Loading the CSS, `useCSSVariable` for the navigation header colors |
| `src/components/ThemeControls.tsx` | `Uniwind.setTheme` and `Uniwind.updateCSSVariables`                |
| `src/app/index.tsx`                | The screen: tokens on `View`, `TextInput` and a native `Switch`    |

## Setup in your own app

```bash
npx expo install uniwind tailwindcss @pickle-ui/tokens@beta
```

`src/global.css` imports, in this order:

```css
@import 'tailwindcss';
@import 'uniwind';
@import '@pickle-ui/tokens/native.css';
```

Override tokens inside `@variant light` and `@variant dark` blocks: Uniwind
ignores the `.dark` selector the web uses, and each theme must declare the same
variables. `src/uniwind-types.d.ts` is generated by Metro; keep it committed so
`tsc` knows the `className` props.
